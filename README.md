# ArenaSector

Простой мобильный и настольный редактор посадочных мест стадиона «Мордовия Арена». Без серверной базы, входа и сторонних библиотек.

## Для чего это приложение

На стадионе выбери трибуну и сектор, добавь ряды и кресла, подстрой смещения и проходы. Когда схема готова, нажми **«PNG»**: браузер скачает один ZIP-архив с PNG всех заполненных секторов. Внутри — папки `A`, `B`, `C`, `D` и файлы вида `C/sector-138.png`. Пустые сектора в экспорт не входят. Эти PNG можно передать подрядчику билетной системы как визуальный образец.

Первый созданный ряд отображается **внизу у поля**, каждый следующий — выше. Ряды можно переставлять стрелками; нумерация ряда и кресла редактируется. На PNG написаны трибуна, номер сектора, номера рядов и мест и направление к полю.

## Возможности

- Схема стадиона с кликабельными секторами и поиском по номеру.
- Добавление и дублирование рядов, смещение целых рядов и отдельных мест, проходы.
- Отдельный режим просмотра и полноэкранный просмотр.
- **Экспортировать в PNG** — все заполненные сектора одним ZIP-архивом, разложены по трибунам.
- **Проект JSON / Импорт JSON** — резервная копия и перенос работы с телефона на ПК.
- Локальное автосохранение в IndexedDB; PWA для офлайн-работы после первой онлайн-загрузки; мобильный и настольный интерфейс.

Нет статусов обследования, примечаний, серверной БД или синхронизации.

**Важно:** браузер может удалить локальное хранилище; регулярно сохраняй JSON. Скачанные PNG не содержат редактируемых данных — для продолжения работы нужен JSON. Приложение использует ориентировочную схему секторов и не подменяет проверку реальной рассадки на стадионе.

## Запуск и публикация

Все файлы статические, npm и сборка не нужны. Для локального запуска: `python -m http.server 8080` и `http://localhost:8080`.

GitHub Pages использует `.github/workflows/pages.yml` и публикует `main` по адресу: <https://vzloman546-design.github.io/ArenaSector/>.

Формат JSON `ArenaSectorProject`, `schemaVersion: 1`; импорт предыдущих резервных копий поддерживается, в том числе если в них остались старые поля `status` или `note` (новый интерфейс их игнорирует).
## Ложи

На общей карте ложи каждой трибуны объединены в один цветной блок «Ложи». Нажмите на него, чтобы выбрать отдельный номер. Трибуна A: 411–405, VIP, 404–401; B: 440–434; C: 433–419; D: 418–412. Каждая ложа по-прежнему редактируется как самостоятельный сектор и экспортируется в отдельный PNG. Поиск по конкретному номеру в списке секторов сохранён.

## Отчётность и PDF

Вкладка **«Отчёты»** показывает число секторов и заполненных секторов, число рядов и посадочных мест,  Есть таблицы по трибунам и каждому сектору (включая отдельные сектора лож). По номеру сектора можно перейти в редактор.

Выбери **все трибуны** или конкретную A/B/C/D и скачай:

- **Сводный PDF** — общие показатели, показатели каждой трибуны и таблица всех секторов с количеством рядов и мест.
- **Подробный PDF** — тот же обзор плюс таблицы каждого заполненного сектора с номерами рядов и количеством мест в каждом ряду.

PDF создаётся прямо в браузере без сервера, через Canvas; русский текст виден на изображениях страниц PDF. Он предназначен для просмотра, распечатки и передачи, а не для выделения и поиска отдельных слов в PDF. Объединённые широкие кресла считаются как **одно посадочное место**. В отчётах по секторам и рядам выводятся только ряды и места. Отчёты строятся из текущего локального проекта; пустые секторы также присутствуют в сводной таблице.

## Компактный редактор

Во вкладке **«Редактор»** схема занимает основную часть экрана. Сверху можно выбрать сектор и ряд. Внизу находятся переключатель **«Ряд / Место»**, стрелки перемещения и кнопки **«＋ Место»** и **«＋ Ряд»**. Выбор кресла на схеме автоматически переводит управление в режим перемещения места. На ПК работают клавиши стрелок, если курсор не находится в поле ввода. Шаг смещения — половина места.

- **«Ряды»** открывает окно со списком рядов: выбор, переименование, перестановка, дублирование, удаление и добавление нового ряда.
- **«Место»** открывает окно для изменения номера, настройки промежутка после кресла и удаления.
- **«Сектор»** открывает окно расположения лестницы и действий над выбранным рядом (перенумерация, выравнивание).
- **«Вместить»** масштабирует схему под свободную область экрана; кнопки +/− регулируют масштаб вручную.
- **«⋯»** открывает меню экспорта PNG, резервного JSON-проекта и импорта.

Прежние данные и формат schemaVersion: 1 сохранены; резервные копии из предыдущих версий поддерживаются. Работает офлайн после первого открытия.

## Лестничные проходы между секторами

В разделе **«Расстановка мест»** есть настройка **«Лестничный проход»**: не отмечать, слева, справа либо с обеих сторон. Она обозначает лестницу **у внешнего края сектора**, по которой зрители поднимаются и спускаются к рядам — это не проход между креслами. Полоса со ступенями показывается в редакторе и просмотре, а также включается в PNG-схему, предназначенную для Билетона. Указанное расположение сохраняется в JSON-проекте отдельно для каждого сектора; старые проекты продолжают открываться без изменений.

Внутреннюю лестницу можно поставить **точно по одной вертикали**, даже если в верхних рядах она располагается после места 15, а в нижних — после места 9. Открой **«Редактор» → «Сектор» → «Вертикальные лестницы» → «Поставить на схеме»**, затем нажми в нужный промежуток между креслами. Появится единая лестничная полоса сверху вниз. Полоса центрируется между креслами, а две стрелки рядом с добавленной лестницей позволяют точно сдвигать её влево или вправо. При установке масштаб схемы не меняется. Альтернатива — в том же окне выбрать соседние места в разделе «После места выбранного ряда», либо открыть конкретное кресло и нажать «Лестница после места». Положение задаётся по горизонтальной координате, а не по номеру места. Можно добавить до 20 вертикальных лестниц и удалить любую из списка. При этом старые лестницы, созданные по порядковым позициям, продолжат отображаться. Кресла раздвигаются только визуально, без изменения исходных координат и номеров, экспорт PNG сохраняет лестницы.

## Рабочее пространство и безопасность редактирования

Редактор работает как единое рабочее пространство: слева находятся инструменты **Выбор, Двигать, Схема, Ряды, Лестница**, в центре — интерактивная схема, справа — свойства выбранного кресла или ряда (на телефоне панель открывается поверх схемы). Масштаб по умолчанию предназначен для редактирования; кнопки **«Рабочий»** и **«Весь сектор»** переключают рабочий масштаб и общий обзор.

- **Перемещение кресел** выполняется только при выбранном инструменте **«Двигать»**; обычный выбор кресел не изменяет их координаты. Ряды можно заблокировать от случайного смещения в панели свойств.
- **Перемещение схемы** доступно инструментом **«Схема»**, пробелом с перетаскиванием или средней кнопкой мыши. Колесо мыши изменяет масштаб схемы; «Весь сектор» показывает общий обзор.
- **Контекстные свойства** позволяют менять номер места или ряда, сдвигать кресло и ряд, создавать промежутки, дублировать и блокировать ряды без постоянного открытия окон.
- **Инструмент «Ряды»** позволяет выделять несколько рядов нажатием на разные ряды, включая телефон; Shift позволяет выбрать диапазон и массово сдвигать, выравнивать, дублировать, блокировать или удалять их. В окне рядов есть **«Создать сразу несколько рядов»** — шаблон с начальным номером, количеством рядов, мест и направлением нумерации.
- **Инструмент «Лестница»** позволяет добавить лестницу на схеме и перетащить уже добавленную вертикальную лестницу непосредственно мышью; в панели свойств также доступны боковые лестницы и точная подстройка стрелками.
- **Отмена/повтор** — кнопки ↶/↷ и Ctrl+Z/Ctrl+Y, до 45 шагов в открытой сессии. Версии проекта можно сохранять вручную кнопкой ◷; до 12 версий хранятся в IndexedDB браузера; кроме ручных копий создаются автоматические снимки после каждых 25 изменений.
- **Проверка перед PNG** — кнопка «Проверка» ищет повторяющиеся номера, пересечения кресел и лестницы, проходящие через кресла, во всех заполненных секторах. Замечания можно открыть на схеме; для экспорта с предупреждениями требуется отдельное подтверждение.

Перед импортом нового JSON приложение сохраняет копию текущего проекта для восстановления. Проект продолжает сохраняться автоматически в IndexedDB. JSON-проект рекомендуется регулярно скачивать как независимую резервную копию. История действий и локальные версии ограничены текущим браузером и не заменяют внешний бэкап.

## Горячие клавиши и быстрый поиск

В редакторе нажми **?** или **Ctrl + /**, чтобы открыть **поисковую справку по сочетаниям**. Есть более 40 команд, они работают при русской и английской раскладке (определяются по расположению клавиш). Обычный набор текста и стандартная отмена внутри активных полей ввода сохраняются.

- **Отмена:** Ctrl + Z — назад, Ctrl + Y или Ctrl + Shift + Z — вперёд. В историю не включается служебное время автосохранения, поэтому каждый шаг соответствует реальному изменению схемы.
- **Инструменты:** 1–5 или V / M / H / R / L — выбор, перемещение кресла, перемещение холста, ряды, лестницы.
- **Работа со схемой:** 0 — уместить сектор, 9 — рабочий масштаб, + и − — масштаб, пробел с перетаскиванием — двигать схему. Стрелки в режиме выбора переходят между креслами и рядами, Shift + ←/→ выделяет соседние кресла для объединения, а в режиме перемещения стрелки сдвигают объект (с Shift — крупный шаг). В режиме лестницы стрелки ←/→ подправляют выбранную лестницу.
- **Создание:** N — место, Shift + N — ряд, B — несколько рядов, Shift + D — дублировать, Delete — удалить после подтверждения, G / Shift + G — промежуток, Shift + L — лестница после места, Shift + R — изменить направление нумерации, K — блокировка ряда.
- **Навигация:** PgUp/PgDn — соседний ряд, [ и ] — соседнее кресло, Home/End — крайнее, F2 — редактирование номера, F или / — быстрый поиск по номеру кресла или ряда.
- **Проект:** Ctrl + S — JSON, Ctrl + Shift + S — сохранить версию, Ctrl + O — импорт JSON, Ctrl + Shift + E — экспорт PNG с проверкой, Alt + 1–4 — вкладки, C — проверка схемы.
- **Буфер редактора:** Ctrl + C и Ctrl + V — копирование и вставка кресел или рядов внутри приложения; Ctrl + A в режиме «Ряды» — выбрать все ряды; Ctrl + M — объединить отмеченные соседние места.

Все сочетания, не относящиеся к приложению, остаются за браузером. Внутренний буфер копирования работает в текущей вкладке, не заменяет системный буфер обмена. **Ctrl + Z в активном поле ввода** использует обычную отмену текста; для отмены редактирования схемы сначала выйди из поля. Импорт JSON также можно отменить после подтверждённой загрузки файла.

## Управление мышью

Редактором можно пользоваться без горячих клавиш. В верхней панели есть кнопка **🖱** с краткой справкой и настройками мыши.

- **Правый щелчок** на кресле, номере ряда, лестнице или пустом месте открывает контекстное меню с подходящими действиями: редактирование номера, добавление, удаление, дублирование, копирование/вставка, управление рядами и лестницами, масштаб, отмена и повтор.
- **Двойной щелчок** на кресле или номере ряда открывает его номер для редактирования; по пустой области показывает весь сектор.
- **Колесо мыши** изменяет масштаб относительно точки под указателем. **Shift + колесо** прокручивает схему по горизонтали.
- **Зажатое колесо** перемещает холст в любом инструменте. Также можно использовать инструмент **«Схема»** или перетаскивать пустой фон правой кнопкой.
- Для выделения нескольких кресел **без клавиатуры** нажми кнопку «Выделить» на панели инструментов или открой контекстное меню кресла → «Выделить несколько мест», затем отмечай кресла обычным кликом. Для ускорения доступны Ctrl + клик (добавить/убрать кресло) и Shift + клик (выбрать диапазон). Объединение выполняется через «Объединить».
- **Боковые кнопки** мыши можно по желанию назначить на Undo/Redo в окне 🖱. Это *отключено по умолчанию*, поскольку некоторые браузеры используют их для навигации по истории страниц; их перехват зависит от устройства и браузера.

Защита данных и прежний формат JSON не менялись. Контекстное меню использует существующие операции проекта, поэтому изменения записываются автосохранением и поддерживают Undo/Redo.
