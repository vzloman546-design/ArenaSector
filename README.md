# ArenaSector

Простой мобильный и настольный редактор посадочных мест стадиона «Мордовия Арена». Без серверной базы, входа и сторонних библиотек.

## Для чего это приложение

На стадионе выбери трибуну и сектор, добавь ряды и кресла, подстрой смещения и проходы. Когда схема готова, нажми **«PNG»**: браузер скачает один ZIP-архив с PNG всех заполненных секторов. Внутри — папки `A`, `B`, `C`, `D` и файлы вида `C/sector-138.png`. Пустые сектора в экспорт не входят. Эти PNG можно передать подрядчику билетной системы как визуальный образец.

Первый созданный ряд отображается **внизу у поля**, каждый следующий — выше. Ряды можно переставлять стрелками; нумерация ряда и кресла редактируется. На PNG написаны трибуна, номер сектора, номера рядов и мест и направление к полю.

## Возможности

- Схема стадиона с кликабельными секторами и поиском по номеру.
- Добавление и дублирование рядов, смещение целых рядов и отдельных мест, проходы.
- Отдельный режим просмотра и полноэкранный просмотр.
- **Экспортировать в PNG** — все заполненные сектора одним ZIP-архивом, разложены по трибунам.
- **Проект JSON / Импорт JSON** — резервная копия и перенос работы с телефона на ПК.
- Локальное автосохранение в IndexedDB; PWA для офлайн-работы после первой онлайн-загрузки; мобильный и настольный интерфейс.

Нет статусов обследования, примечаний, серверной БД или синхронизации.

**Важно:** браузер может удалить локальное хранилище; регулярно сохраняй JSON. Скачанные PNG не содержат редактируемых данных — для продолжения работы нужен JSON. Приложение использует ориентировочную схему секторов и не подменяет проверку реальной рассадки на стадионе.

## Запуск и публикация

Все файлы статические, npm и сборка не нужны. Для локального запуска: `python -m http.server 8080` и `http://localhost:8080`.

GitHub Pages использует `.github/workflows/pages.yml` и публикует `main` по адресу: <https://vzloman546-design.github.io/ArenaSector/>.

Формат JSON `ArenaSectorProject`, `schemaVersion: 1`; импорт предыдущих резервных копий поддерживается, в том числе если в них остались старые поля `status` или `note` (новый интерфейс их игнорирует).
## Ложи

На общей карте ложи каждой трибуны объединены в один цветной блок «Ложи». Нажмите на него, чтобы выбрать отдельный номер. Трибуна A: 411–405, VIP, 404–401; B: 440–434; C: 433–419; D: 418–412. Каждая ложа по-прежнему редактируется как самостоятельный сектор и экспортируется в отдельный PNG. Поиск по конкретному номеру в списке секторов сохранён.

## Отчётность и PDF

Вкладка **«Отчёты»** показывает число секторов и заполненных секторов, число рядов и посадочных мест,  Есть таблицы по трибунам и каждому сектору (включая отдельные сектора лож). По номеру сектора можно перейти в редактор.

Выбери **все трибуны** или конкретную A/B/C/D и скачай:

- **Сводный PDF** — общие показатели, показатели каждой трибуны и таблица всех секторов с количеством рядов и мест.
- **Подробный PDF** — тот же обзор плюс таблицы каждого заполненного сектора с номерами рядов и количеством мест в каждом ряду.

PDF создаётся прямо в браузере без сервера, через Canvas; русский текст виден на изображениях страниц PDF. Он предназначен для просмотра, распечатки и передачи, а не для выделения и поиска отдельных слов в PDF. Объединённые широкие кресла считаются как **одно посадочное место**. В отчётах по секторам и рядам выводятся только ряды и места. Отчёты строятся из текущего локального проекта; пустые секторы также присутствуют в сводной таблице.

## Компактный редактор

Во вкладке **«Редактор»** схема занимает основную часть экрана. Сверху можно выбрать сектор и ряд. Внизу находятся переключатель **«Ряд / Место»**, стрелки перемещения и кнопки **«＋ Место»** и **«＋ Ряд»**. Выбор кресла на схеме автоматически переводит управление в режим перемещения места. На ПК работают клавиши стрелок, если курсор не находится в поле ввода. Шаг смещения — половина места.

- **«Ряды»** открывает окно со списком рядов: выбор, переименование, перестановка, дублирование, удаление и добавление нового ряда.
- **«Место»** открывает окно для изменения номера, настройки промежутка после кресла и удаления.
- **«Сектор»** открывает окно расположения лестницы и действий над выбранным рядом (перенумерация, выравнивание).
- **«Вместить»** масштабирует схему под свободную область экрана; кнопки +/− регулируют масштаб вручную.
- **«⋯»** открывает меню экспорта PNG, резервного JSON-проекта и импорта.

Прежние данные и формат schemaVersion: 1 сохранены; резервные копии из предыдущих версий поддерживаются. Работает офлайн после первого открытия.

## Лестничные проходы между секторами

В разделе **«Расстановка мест»** есть настройка **«Лестничный проход»**: не отмечать, слева, справа либо с обеих сторон. Она обозначает лестницу **у внешнего края сектора**, по которой зрители поднимаются и спускаются к рядам — это не проход между креслами. Полоса со ступенями показывается в редакторе и просмотре, а также включается в PNG-схему, предназначенную для Билетона. Указанное расположение сохраняется в JSON-проекте отдельно для каждого сектора; старые проекты продолжают открываться без изменений.
