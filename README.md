# ArenaSector

Мобильный и настольный редактор схем секторов и посадочных мест стадиона. Работает без серверной базы и без сторонних библиотек.

## Возможности

- Карта стадиона с четырьмя трибунами A, B, C, D и выбором сектора.
- Ряды, индивидуальные номера кресел, ручные сдвиги и проходы, дублирование рядов.
- Раздельные вкладки «Редактор» и «Просмотр», полноэкранный просмотр, масштабирование.
- Автоматическое сохранение в IndexedDB **текущего браузера и устройства**.
- Импорт и экспорт всего проекта в JSON.
- PWA и офлайн-доступ после первой онлайн-загрузки на GitHub Pages.
- Адаптивный интерфейс для телефона и ПК.

Начальное количество мест намеренно равно нулю: точные ряды и места вводятся по результатам обследования трибун. В качестве основы карты используется предоставленное изображение стадиона, поверх которого расположены зоны нажатия. Расположение границ зон нажатия приблизительное, а схема не является техническим чертежом.

## Как пользоваться

1. Выберите сектор на схеме или в списке.
2. Откройте вкладку «Редактор» и добавьте ряд, указав его номер и количество кресел.
3. Выберите ряд и нажмите на конкретное кресло; измените номер, сделайте смещение или добавьте проход после кресла.
4. Проверьте результат во вкладке «Просмотр» и отметьте статус сектора.
5. Регулярно нажимайте «Экспорт проекта» и храните JSON как резервную копию. Для переноса между устройствами используйте «Импорт проекта».

**Важно:** IndexedDB может быть очищена средствами браузера; GitHub Pages не хранит внесённые пользователем данные. Автоматической синхронизации устройств нет. При импорте текущий локальный проект заменяется.

## GitHub Pages

Статические файлы находятся в корне репозитория. В `Settings → Pages` выберите `Deploy from a branch`, ветку `main`, папку `/(root)` и сохраните настройки. Адрес сайта при стандартной конфигурации: `https://vzloman546-design.github.io/ArenaSector/`.

Для локальной разработки достаточно `python -m http.server 8080` и затем открыть `http://localhost:8080` (для офлайн-PWA нужна HTTPS-публикация). Никакой сборки и npm не требуется.

## Формат хранения

JSON содержит `kind: "ArenaSectorProject"`, `schemaVersion: 1`, `sectors`, `rows`, `seats`. Для кресла хранятся номер и координаты `x`, `y` в условных единицах SVG. Импорт проходит проверку структуры, но не проверяет соответствие реальному стадиону.
